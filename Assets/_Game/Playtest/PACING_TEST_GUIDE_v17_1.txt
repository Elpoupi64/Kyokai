================================================

OBJECTIF
--------
Mesurer une partie complète en Nouvelle partie, sans connaître le niveau,
et viser une durée totale comprise entre 08:00 et 10:00.

NOUVEAU : CHAÎNE 4 POSSÉDÉE
----------------------------
La salle contient trois relais :
- relais A cyan : mode ÉTHÉRIQUE ;
- relais B cuivre : mode NORMAL ;
- relais C cyan : mode ÉTHÉRIQUE.

Le premier relais réveille un second Doryoku-3.
La porte de sortie ne s'ouvre que lorsque :
1. les trois relais sont synchronisés ;
2. l'automate réveillé est détruit.

Le but est d'ajouter 60–90 secondes de gameplay réel et non une attente.

NOUVELLE POURSUITE
------------------
La course comporte trois micro-événements :
1. conduite rompue / saut ;
2. passage spectral nécessitant K ;
3. valves vapeur cycliques à esquiver.

MÉTHODE DE CALIBRATION
----------------------
Faire au minimum 3 runs Nouvelle partie :
- un run par le développeur ;
- un run par quelqu'un qui connaît peu le niveau ;
- idéalement un run par quelqu'un qui ne l'a jamais vu.

Ne pas modifier les timings après un seul run.

Si TOTAL < 08:00 :
- regarder les sections marquées [RAPIDE] ;
- rallonger seulement celles qui sont réellement trop courtes.

Si TOTAL > 10:00 :
- regarder [LONG] ;
- réduire puzzle, difficulté ou durée du boss avant de toucher à la vitesse de Kenjiro.
